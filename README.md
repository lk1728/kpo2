# ПОС

Консольное приложение для преподавательской оценки студентов на Go 1.22.

## Запуск

```bash
go run ./cmd/pos
```

Проверка:

```bash
go test ./...
go vet ./...
```

## Возможности

- Добавление и просмотр студентов и критериев.
- Выставление, исправление и отмена оценок.
- Расчет текущего и итогового балла.
- Просмотр итогов всех студентов и экспорт в CSV.

Данные хранятся в памяти до завершения программы. CSV сохраняется в файл.

## Архитектура

Используется Ports and Adapters.

| Папка | Назначение |
|---|---|
| `internal/domain` | Модель, инварианты, расчет итогов |
| `internal/application` | Сценарии, интерфейсы хранилища и экспорта |
| `internal/adapters` | Консоль, хранилище в памяти, CSV |
| `cmd/pos` | Создание зависимостей и запуск |

Зависимости: `adapters -> application -> domain`.

Домен не зависит от консоли и файлов. Зависимости передаются через конструкторы. DI-контейнер не используется.

## DDD

- Единый язык модели: студент, критерий, оценка, курс, итог.
- Entity: `Student`, `Criterion`, `Course`, различаются по ID.
- Value Object: `Score`, определяется значением балла.
- Корень агрегата: `Course`, управляет студентами, рубрикатором и оценками одного курса.
- Repository: порт `CourseRepository`, реализация находится в `adapters/memory`.
- Domain Service: `TotalCalculator`, рассчитывает итог из критериев и оценок.

Модель запрещает пустые имена, неположительные максимумы и веса, неконечные числа, оценки вне диапазона и оценки неизвестным студентам или по отсутствующим критериям. Повторное выставление оценки заменяет предыдущую.

## Расчет

Итог по шкале от 0 до 10:

`10 * sum(score / max_score * weight) / sum(weight)`

В итоговом режиме отсутствующие оценки считаются нулями. В текущем режиме учитываются только критерии с выставленными оценками.

## Паттерны

| Группа | Паттерн | Применение |
|---|---|---|
| Порождающие | Фабрика | `NewEvaluation` создает оценку после проверки студента, критерия и балла |
| Структурные | Фасад | `application.Service` предоставляет консоли готовые сценарии, включая расчет и экспорт |
| Поведенческие | Стратегия | `ScoreStrategy` позволяет выбирать итоговый или текущий расчет |

## Демонстрация

Добавить студента и критерий с максимумом 10 и весом 1. Выставить 8 баллов, получить итог 8.00 и экспортировать его через пункт меню 10.

## Тесты и ИИ

Юнит-тесты проверяют инварианты, исправление и отмену оценок, оба режима расчета и обработку ошибочных данных.

ИИ использовался для юнит-тестов, а также проверки работы приложения.
